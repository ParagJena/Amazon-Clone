# Amazon-Clone
Amazon homepage clone built using HTML and CSS
A frontend recreation of the Amazon shopping website built using HTML and CSS. This project focuses on recreating the visual structure, layout, navigation, product sections, and overall shopping interface of Amazon.

📌 About the Project

This project was created to practice and demonstrate core frontend web development skills by building an Amazon-inspired e-commerce interface from scratch.
The website focuses on creating a familiar e-commerce layout using semantic HTML and CSS styling, including navigation, product sections, banners, and shopping-related UI components.

✨ Features

Amazon-inspired navigation bar
Search bar UI
Product category sections
Product cards and promotional sections
Hero/banner section
Responsive and structured page layout
Hover effects and interactive styling
Clean and organized HTML/CSS structure

🛠️ Technologies Used

HTML5 – Website structure and content
CSS3 – Styling, layout, positioning, and visual design
